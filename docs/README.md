## 서비스 소개
project: 대파마켓 

대파마켓은 기존 중고거래 플랫폼에서 발생하는 가격 결정과 협상 과정의 비효율성을 보완한 중고거래 플랫폼이다.
판매자가 설정한 가격 범위 내에서 시스템 알고리즘으로 거래가 성사될 수 있는 가격으로 변동시켜주는 중고거래 서비스.

대파마켓은 판매자가 상품을 등록할 때, 가격 정책을 미리 설정한다.
- 판매 시작 가격
- 최소 판매 가격

판매자와 구매자의 회전율이 중요해. 그래서 둘 다의 유입이 많아야 하는데 판매자에게는 빨리 팔리고, 가격 고민을 줄이고, 헐값 판매를 막는다, 네고의 스트레스를 없앤다 라는 이미지를 줘야 해. 

상품 상세에는 페이지에 상품 가격 변동을 그래프로 보여주고 가격이 변동된 이유도 보여줘야 해.



## 자동 가격 조정 시스템

이 기능의 핵심은 단순히 "등록한 지 오래되면 가격을 내린다"거나 "관심 수가 많으면 가격을 올린다"가 아니다.

유사 상품의 실제 거래가격, 현재 상품의 사용자 반응, 현재 가격과 시장가격의 차이, 이전 가격 변경 이후의 반응을 종합해서 가격을 자동으로 재평가하는 시스템으로 구현해야 한다.

구현할 때 아래 정책을 반드시 지켜줘.

1. 상품은 등록 시 판매자가 다음 가격을 입력한다. 
- initialPrice: 최초 등록 가격
- minimumPrice: 판매자가 허용하는 최저 판매 가격

자동 가격 조정은 모든 상품에 필수 적용된다.
사용자가 자동 가격 조정 여부를 ON/OFF 할 수 있는 옵션은 만들지 않는다.
자동 알고리즘으로 최초 등록 가격보다 가격이 높아져서는 안되고 최저 판매가격보다 낮아져서도 안된다.

2. 상품 수요 판단
단순 조회수나 관심수로 판단하면 안 된다.
같은 카테고리 평균과 비교한 조회 대비 관심 전환율을 사용한다.
최근 48시간동안의 상세 조회 수, 관심 등록 수, 재조회 수 데이터를 사용한다.

수요 점수에 대한 비중을 다음 과 같이 사용한다.
조회 반응 15%
조회 대비 관심 등록 전환율 50%
재조회 반응 35%

수요 상태는 세단계로 분류한다.
LOW
NORMAL
HIGH

70% 미만 : LOW
70% ~ 130% : NORMAL
130% 초과 : HIGH

3. 시장가격 계산
시장가격은 실제 판매 완료된 유사 상품의 거래가격을 기준으로 계산한다.
우선 순위는 다음과 같다.
1순위 : 동일 모델 + 비슷한 상품 상태
2순위 : 동일 모델
3순위 : 동일 세부 카테고리
최근 30일 판매완료 데이터를 사용하되 없으면 최근 60일 판매완료 데이트를 사용한다.
시장가격은 과도 이탈된 가격 제외를 위해 단순 평균보다 중앙값을 사용한다.

예시)
판매완료된 가격 리스트: 45000, 46000, 47000, 48000, 70000
시장가격 : 47000

4. 기본 가격 하락 정책
시장가격보다 10% 이상 비싸고 수요 LOW : 가격 -5%
시장가격보다 5~10% 비싸고 수요 LOW : 가격 -3%
시장가격보다 1~5% 비싸고 수요 NORMAL : 가격 -2%
시장가격보다 0~1% 비싸고 수요 NORMAL : 가격 KEEP
시장가격 대비 ±5% 범위 : 가격 KEEP
시장가격보다 비싸더라도 수요 HIGH : 가격 KEEP

5. 데이터가 거의 없는 Cold Start
서비스 초기에 유사 거래 데이터가 없을 수 있다.
이 경우 알고리즘이 시장가격을 아는 척해서는 안 된다.
상품 등록 후 24시간동안 무조건 가격 유지
그 이후에도 사용자 반응 데이터가 부족하면 가격 KEEP 한다.

6. 실행 순서
  1. 판매중 상품 조회
  2. 등록 또는 마지막 평가 이후 24시간이 지났는지 확인
  3. 시장가격 계산
  4. 수요 점수 계산(LOW/NORMAL/HIGH 판정)
  5. 가격 하락 정책에 따라 가격 변경



## 로그인/회원가입
이메일과 비밀번호를 입력하여 서비스 이용 할 수 있다. 

입력 정보: 닉네임, 이메일, 비밀번호, 주소, 프로필 이미지
중점사항: 필수 입력값 검증, 이메일 중복 확인, 비밀번호 유효성 검사, 회원가입 성공/실패 처리

## 메인 페이지
자동 가격 인하 시스템으 직관적으로 이해할 수 있어야 한다.

- 인기상품(사용자가 관심가지는 상품 view, click)
- 곧 썰리는 상품(가격이 내려가고 거래가 임박했을 때) 

서비스 컨셉을 이해하고, 상품 탐색까지 자연스러운 이동
현재 가격 변동 강조

## 상품 등록 페이지 
판매자가 상품과 가격 정책을 등록한다. 

상품정보: 상품이미지, 상품명, 카테고리, 상품 설명, 거래 지역
가격 정책: 판매 시작 가격, 최소 판매 가격, 가격 인하 금액, 가격 인하 주기

## 상품 상세 페이지 
구매자가 상품 정보를 확인하고 가격 변동 상황을 파악한 후 구매할 수 있다.

정보: 상품이미지, 상품명, 카테고리, 상품 설명, 거래 지역, 판매 시작 가격, 최소 판매 가격, 상품 상태

## 상품 검색 페이지
상품 목록 검색은 원하는 조건으로 상품을 검색할 수 있는 기능이다.

왼편에 카테고리를 선택할 수 있게 하고 지역과, 가격대도 조건으로 지정할 수 있다.
정렬은 최신순, 등록일 순, 낮은 가격순, 높은 가격순, 관심 많은 순, 많이 썰린 순(최초 가격 대비 할인율이 큰 상품), 시장가 대비 저렴한 순(유사 상품 시세보다 현재 가격이 낮은 상품)으로 할 수 있게 한다.


## 마이페이지
마이페이지에는 내 활동, 판매관리, 구매내역, 관심상품, 설정과 같은 하위 기능이 있다.

내 활동 : 에는 판매하고 있는 상품 개요, 구매한 상품 개요, 관심상품 개요를 간단히 보여준다
판매 관리 : 판매하고 있는 상품의 리스트를 보여준다.
구매내역 : 구매를 한 상품의 리스트를 보여준다.
설정 : 하위 메뉴로 프로필 수정(닉네임, 프로필 이미지, 거래지역, 주소), 거래 설정(기본 거래 지역, 채팅 가능 시간), 계정 설정(비밀번호 변경, 로그아웃, 회원탈퇴)

## DB컬렉션(몽고DB)

[users:회원]
_id : 고유 키값
email : 아이디로 사용할 것이고 고유의 값
nickname : 닉네임
address : 주소
passwordHash : 비밀번호 해쉬값
profileImage : 프로필 이미지 url
createdAt : 가입일
role : 일반회원/관리자



[products:상품]
_id : 고유 키값
images : 상품이미지(최대 5개)
name : 상품명
category : 카테고리
info : 상품 설명
initialPrice : 판매 시작 가격
minimum : 최저 판매 가격
region : 거래 지역
status : 상품 상태 (최상, 상, 중, 하)
createdAt : 상품등록 날짜


[watchlists:관심목록]
_id : 고유 키값
productId : 상품 키값
userId : 회원 키값
createdAt : 관심목록 추가한 날짜

[transactions:거래]
_id : 고유 키값
buyerId : 구매자
sellerId : 판매자
productId : 상품 키값
price : 거래 성사 가격
createdAt : 거래 성사 날짜

[priceChange:가격변동]
_id : 고유 키값
productId : 상품 키값
changedAt : 변경된 날짜
previousPrice : 이전 가격
newPrice : 변경된 가격
seq : 변경된 횟수
reason : 변경 이유
status : 가격이 올랐는지 내렸는지 KEEP인지(UP/DOWN/KEEP)
